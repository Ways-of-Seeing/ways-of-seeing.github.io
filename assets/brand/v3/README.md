# Ways of Seeing — Identidade v3

Paleta: `#060914` (ink), `#6957FF` (ultraviolet), `#D8FF47` (phosphor), `#EDEAE2` (lunar).

- `master-orbital-mark.png`: arte texturizada/cinematográfica; use em capas e aberturas.
- `logo-mark.svg`: marca colorida sem nome; use em tamanhos médios e grandes.
- `logo-lockup-*.svg`: logo com nome, para superfícies escuras e claras.
- `logo-monochrome-*.svg`: uma tinta, para impressão, favicon e contextos restritos.

Os PNGs derivados e o GIF são versões práticas para publicação. Os SVGs são as fontes de uso preferenciais.
